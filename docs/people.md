# Updating people and acknowledgements

Edit `src/scripts/people.js` to replace each placeholder's name and short
description. The groups contain two supervisors, one research collaborator and
three acknowledgements. All six currently use an original generic cartoon avatar.

Put replacement portraits in `public/assets/people/` and update each person's
`avatar` path. Remove the “Placeholder profiles” label in `render()` when the
profiles are final. Run `npm run build` and `npm run check` after changes.
